This was a group course project where we had to build a portable xray stand from scratch. We used metal sheets and basic items like lead screws,
to build a fully motorised and functional stand with up and down motion.

If we entered a positive number +x in the serial monitor, then it would move up by x cm distance from the current position. If we entered
a negative number -x, then it would move down by x distance.

I was the team leader of this project with 5 members. I organised meetings, delegated tasks to my team members and even helped them in completing
their tasks.

Components Used- 
1. Arduino Uno
2. YS-DIV268N-5A motor driver
3. 10.1 kg-cm NEMA 23 motor
4. Arduino IDE
5. Autodesk Fusion
6. Pro-Range A Grade NMC N18650CH 14.8V 2500mAh 3C 4S1P Li-Ion Battery Pack

We had 3-d printed the coupler as we could not find the correct size.
